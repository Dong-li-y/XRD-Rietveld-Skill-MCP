# 02 工具速查表

## 1. 先路由，再动手（4 个 Skill 的分工）

下任务前先判断属于哪一类，**不同类走不同 Skill**，不要一个 Skill 包打天下：

| 你的任务 | 用哪个 Skill | 不要做什么 |
|---|---|---|
| 单张图、已知相、标准单相 Rietveld | `gsas-ii-rietveld-refinement` | 不要用多相 QPA 流程 |
| 变温 / 原位序列、逐帧精修与前后向稳健性 | `gsas-ii-rietveld-refinement`（序列路由） | 不要跨相集变化沿用同一相分数约束 |
| 一张图 ≥2 个已声明相、要相分数（QPA） | `gsas-ii-multiphase-refinement`（Beta） | 不要用归一化后的 HAP Scale 冒充重量分数 |
| 相还不知道是什么 | 先做相鉴定，不要直接精修 | `unknown` 相集禁止出 QPA 数字 |
| 已经精修完成，要出版级图 | `rietveld-plotting` | 画图**只读** `.gpx`，不允许回改任何精修参数 |
| 想要"一条命令跑完全流程"的脚本化 | `gsas2-xrd-refinement` | 阶段失败会自动回退，但仍要人工看残差 |

三条硬边界（Skill 里写死的"停规则"）：

1. 精修、判定、画图**三权分立**：画图 Skill 校验 `.gpx` 哈希进出一致，绝不改模型。
2. **未解释的强残差峰**存在时，不允许给出"结构已定"的结论，只能报"待科学复核"。
3. 相关度 ≥ 95 %、SVD 奇异、方向敏感性未解、相分数为负 → 一律 `review`，不允许当结论。

## 2. MCP 的 19 个工具

调用方式：`python -m gsas2_mcp_server`（stdio）。参数名与默认值照抄下表。

### 2.1 项目管理（4）

| 工具 | 参数 | 说明 |
|---|---|---|
| `create_project` | `name="untitled"` | 新建 `.gpx`（生成在临时项目目录，可用 `save_project` 另存） |
| `load_project` | `path`（必填，绝对路径） | 加载已有 `.gpx` |
| `save_project` | `path=""` | 保存；空则存回原路径 |
| `project_summary` | — | 直方图/相/晶胞/原子数/当前自由变量一览；**每步之后都值得调用一次** |

### 2.2 数据与结构（5）

| 工具 | 参数 | 说明 |
|---|---|---|
| `inspect_data_file` | `datafile` | 不需要项目即可用：报告格式、点数、2θ 范围、强度范围（先探格式再导入，能省一轮返工） |
| `add_powder_histogram` | `datafile`, `iparams=""`, `fmthint=""` | 导入衍射数据；**无内嵌仪器参数的格式必须给 `.prm`**；`fmthint` 可传 `RAS`/`xye`/`fxye` 等 |
| `add_phase` | `cif_file`, `phase_name=""`, `histograms=None` | 从 CIF 加相并关联直方图（默认全部） |
| `list_histograms` | — | 各直方图的 limits / wR / 反射数 |
| `list_phases` | — | 各相的空间群 / 晶胞 / 原子 |

> **多相必读**：`add_phase` 只设相分数初值，**refine 标志默认关闭**。多相时必须显式释放相分数（见 §3.2），否则第二相被冻结在初值，精修"收敛"了却完全用不上第二相。

### 2.3 参数设置（6）

| 工具 | 参数 | 说明 |
|---|---|---|
| `set_refinement` | `params`（JSON 字符串） | 项目级配方，键：`set` / `clear` / `once`，可加 `histograms` / `phases` 限定范围 |
| `set_histogram_params` | `histogram=""`, `params` | 直方图级：本底、限制、仪器 U/V/W、样品参数 |
| `set_phase_params` | `phase=""`, `params` | 相级：`Cell`、`Atoms`、HAP（Size/Mustrain/Pref.Ori.） |
| `get_variables` | — | 当前自由变量清单（**每次 refine 前后各看一次**） |
| `hold_variable` | `var_name` | 固定某变量（收敛不稳时最有效的旋钮） |
| `free_variable` | `var_name` | 释放某变量 |

`set_refinement` 的 `params` 示例（照抄可用）：

```json
{"set": {"Limits": [10.0, 130.0],
         "Background": {"no. coeffs": 3, "refine": true},
         "Sample Parameters": ["Scale"],
         "Instrument Parameters": ["U", "V", "W"],
         "Cell": true},
 "clear": {"Instrument Parameters": ["X", "Y"]}}
```

### 2.4 精修与结果（4）

| 工具 | 参数 | 说明 |
|---|---|---|
| `refine` | `max_cycles=0` | 执行精修。**`max_cycles>0` 会上调 `Controls['max cyc']`（GSAS-II 默认 3 轮，经常在收敛前停下）**；返回 `residuals` + `gsas2_status` + `max_shift_over_esd`，未收敛时给出 `convergence_warning` |
| `get_results` | — | 残差（wR/R/wRmin/GOF）+ 晶胞（含协方差 esd）+ 原子坐标/Uiso |
| `export_results` | `path=""` | 导出 JSON 结果 |
| `export_plot` | `path=""` | 导出拟合图 PNG（通用 matplotlib 图，非出版级，且不裁剪到 Limits 区间） |

## 3. 推荐的调用顺序

### 3.1 单相标准流程

```
inspect_data_file → create_project → add_powder_histogram(带 .prm) → add_phase
→ project_summary → set_refinement(本底+标度) → refine(max_cycles=12)
→ set_refinement(+晶胞) → refine(max_cycles=12) → get_variables
→ set_refinement(+Zero+U/V/W/X/Y/SH-L+位移) → refine(max_cycles=12)
→ get_results → export_results → export_plot → save_project
```

判断"要不要继续加参数"的唯一标准是**`max_shift_over_esd ≤ 1` 且 wR 明显下降**；shift/esd 还在几十上百，就不是"精修完成"。

### 3.2 多相流程（关键差异）

1. `add_phase` 逐个加相并关联同一张图。
2. 阶段一：用**直方图标度**拟合"标度 + 本底"。
3. 阶段二起：**固定直方图标度、释放各相分数**（`set_phase_params` 的 HAP `Scale`）。
   *理由：两者相差一个整体自由度，同时释放时两相分数高度相关，GSAS-II 报 `SVD problem(s) likely from :0:Scale` 后开始丢参数。*
4. 参考相选择：取**丰度高、峰分离好、结构稳定**的相；不要机械地锚定痕量相。
5. 相分数只认 GSAS-II 的协方差质量分数（`ComputeMassFracs`），**不要把归一化 HAP Scale 当重量分数报告**。

### 3.3 仪器轮廓（U/V/W）三条线

- 有标定文件：锁定轮廓做定量，别动 U/V/W。
- 无标定文件：**不放开 U/V/W**，或只放开 W，并在报告里声明 `uncalibrated`。
- 自行反解 U/V/W：注意 GSAS-II 参数化的是**高斯方差** σ²(2θ) = U·tan²θ + V·tanθ + W（cdeg²），`FWHM = 2.3548·σ`。
  用实测 FWHM² 直接灌入会宽 2.35 倍，wR 会钉在 ~30 % 且无法用标度/本底补救 —— **要除以 5.5452**。

## 4. 结果自检清单（报告前逐条过）

- [ ] `get_variables` 确认每一步真的释放了预期的变量（没释放 = 该阶段白跑）
- [ ] `max_shift_over_esd ≤ 1`（不是的话不许写"收敛"）
- [ ] 晶胞值带 GPX 协方差 esd，不要手写括号
- [ ] 残差峰审计：列出最大的未解释正残差峰，或明确说明"无显著未解释峰"
- [ ] 多相：重量分数来自协方差质量分数，且各相有有限正 esd
- [ ] 幻影相检验：候选相的两条最强线是否真的出现；给自由晶胞看是否"自走"
- [ ] 未知相/未识别杂相单独列出，不并入结论
