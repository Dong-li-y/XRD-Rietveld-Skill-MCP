## 版本 1 · 公众号 / 知乎长文导语（约 300 字）

**标题备选**
- 《把 Rietveld 精修交给 AI：4 个 Skill + 19 个工具的开源尝试》
- 《AI 代理做粉末 XRD 精修，卡在哪？我们把它跑通了》
- 《精修不等于点完按钮：一份能复核的 XRD 精修 AI 工作流》

**正文**

> 粉末 XRD 精修的门槛不在"会不会用 GSAS-II"，而在同样的坑要反复踩：第二相分数忘了释放、
> 放开 Zero 把晶胞带跑、U/V/W 按 FWHM² 灌进去结果 wR 永远卡在 30 %……
>
> 我们把这套流程做成了 AI 代理可以直接用的两件东西：
> **4 个 Skill 管"怎么修"**（流程、判据、报告口径），**1 个 MCP 服务器管"能动手"**（19 个 GSAS-II 工具，
> 从建项目、导入数据、加相、设参、精修到导出结果）。
>
> 它不是"AI 说了算"：精修、判定、画图严格分离；晶胞带 GSAS-II 协方差 esd；
> 数字从磁盘 JSON 读入；产物带 sha256；被否的方案、"粉末 XRD 证明不了什么"的边界，
> 全部写进报告。判一个候选第二相是否存在，用的是三条互相独立的判据（线位缺失 / 晶胞是否自走 /
> 逐阶段模型胜负），任何一条打掉就不进结论。
>
> 打包自检时还揪出并修好了 MCP 里一个 `refine` 恒报失败的缺陷：本版
> `Project.refine()` 恒返回 `None`，包装层却把它当失败信号；同时 GSAS-II 默认只迭代 3 轮，
> 未收敛从不提示。修后自检 12/12 步通过，官方 PbSO₄ 样例经 MCP 全程驱动收敛到 wR 12.87 %（默认 3 轮时是 63.80 %）。
>
> 包里有：Skill 源码、MCP 服务器、安装与排错文档、实测案例（含 GSAS-II 公开样例的复现脚本与结果文件）、
> 缺陷修复记录。欢迎同行试用、提 issue、一起补坑。

**English**

> **XRD Rietveld refinement skills + MCP (2026-10-12)**
> Four GSAS-II refinement skills (single phase / multiphase QPA / publication plotting / fully automated
> scripted workflow) plus an MCP server exposing 19 GSAS-II tools.
> Refinement, phase judgement and plotting are strictly separated; every reported number carries
> covariance-derived esd and file hashes; instrument-profile status and cell/zero conventions are declared
