## 案例 A · 匿名化案例：候选第二相"采纳 / 否证"的三条独立判据

**问题类型**（方法层面通用）：一张粉末 XRD 图 + 宿主结构已定，另有 1–2 个候选第二相结构模型，
需要判断"候选相是否真的存在"而不是"哪个模型 wR 更低"。

**做法**：把判据分成互相独立的三条，**每条都能单独否证一个候选相**。

### ① 线位判据（与精修无关的物理证据）

扣掉宿主能解释的反射后，把剩下的可测峰逐条列出：

- 候选相**必须**出现它自己的**两条最强反射**；
- 若两条最强线在图上是本底 → 该相**不存在**，无论 wR 是否下降；
- 若两条强线属于**不同晶面族**，则"取向择优"不能作为借口（取向能压一族，压不了两族）。

### ② 晶胞自走判据（区分真结构与幻影相）

给候选相一个自由晶胞再精修：

- **真结构**：晶胞收敛在参考值附近（几个百分点量级以内）；
- **幻影相**：晶胞被邻峰"吸走"，跑到与参考值严重偏离、且 esd 放大到失去约束的状态 —— 这是
  "该相其实没有被数据支撑"的特征信号，比 wR 更早暴露问题。

### ③ 逐阶段胜负判据（模型比较）

同一张图、**同一套峰形参数**，让各候选模型跑**同一套阶段**（本包推荐 9 阶段，见 `docs/02`）：

- 比较"零偏移分支"的阶段结果（放开 Zero 会让晶胞整体漂移，不是公平口径）；
- 统计候选模型在各阶段的胜负，而不是只看某一个阶段的最低 wR；
- **参数更少优先**：增加一个相只带来极小改善、却多出若干自由参数时，不采纳。

### ④ 边界必须写进报告

- 粉末 XRD 对散射因子接近的原子（如 3d 过渡金属之间）**不可分辨**，同构的多种化学计量可以给出同一套线 ——
  只能支持"该结构族存在"，不能直接给出确切化学计量；
- 无法归属的残余峰**单列为未识别杂相**，不并入结论；
- 被否证的方案连同**否证理由**留档，避免下次重复试。

> 这套判据的价值不在"跑出了漂亮数字"，而在**允许被数据否证**：候选相被三条判据中的任意一条打掉，
> 就不再进结论；剩下的疑点原样保留在报告里。

## 案例 B · MCP 服务器端到端验证（GSAS-II 官方 PbSO₄ 公开样例）

打包时执行 MCP 自带自检脚本，**发现并修复了 `refine` 工具恒报失败的缺陷**（详见 `docs/05`）。
本案例全程使用 GSAS-II 自带的 PbSO₄ 示例数据，与任何课题组数据无关。

### 修前

```
第 8 步 refine → RuntimeError: Refinement failed (GSAS-II returned no result)
```

而 GSAS-II 自己刚打印过 `***** Refinement successful *****` —— 包装层把成功的精修判成失败，
12 步自检中断在第 8 步，任何产物都没生成。

根因：本机 GSAS-II 的 `GSASIIscriptable.Project.refine()` **没有 return 语句，恒返回 `None`**；
加上 GSAS-II 默认只迭代 **3 轮**（`Controls['max cyc'] = 3`），精修其实停在 wR = 63.80 %、shift/esd = 55.1。

### 修后

| 项 | 结果 |
|---|---|
| 自检 12 步 | **12/12 `[OK]`，exit = 0**；产出 `.gpx` / `_results.json` / `_plot.png` |
| `refine` 返回 | residuals + `gsas2_status` + `max_shift_over_esd` + 未收敛警告 |
| 增量迭代 | `refine(max_cycles=12)` 可主动提高轮数 |

### 收敛实测（全程只用 MCP 工具函数）

| 阶段 | 释放参数 | 收敛 wR | GOF | 末轮 shift/esd |
|---|---|---|---|---|
| S1 | 3 项本底 + 标度 + 晶胞 | 31.6808 % | 6.6184 | 0.759 |
| S2 | + Zero + U/V/W/X/Y/SH-L + 样品位移 | **12.8650 %** | **2.6876** | 0.486 |

最终晶胞：a = 8.481861(138)、b = 5.399835(90)、c = 6.961628(116) Å，V = 318.847(106) Å³
（PbSO₄ 文献 a≈8.48 / b≈5.398 / c≈6.958 Å）。拟合图见 `verify/e2e_out_converged/pbso4_plot_converged.png`。

**一句话**：同一份数据、同一套工具，把"我以为跑完了"换成"确认 shift/esd ≤ 1"，**wR 63.80 % → 12.87 %**。
