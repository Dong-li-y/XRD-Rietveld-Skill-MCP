```bash

bash verify/leak_scan.sh
# 等价于：按关键词表逐组 grep -rniE，另加一次本机用户名路径检查（Users\<user> / Users/<user>）
```

- `verify/leak_scan.sh` —— 核查脚本（不含任何关键词，从包外表读取）
