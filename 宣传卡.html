方法与验证（可复核）

  • 候选相采纳 / 否证的三条独立判据：① 候选相的两条最强反射必须出现（缺一即否，且两族强线不可能被取向压掉）； ② 给自由晶胞看它是否"自走"——真结构收敛在参考值附近，幻影相会被邻峰吸走且 esd 失去约束； ③ 同图同峰形参数下逐阶段比较模型胜负，并按"参数更少优先"取舍 结论必须写边界：粉末 XRD 对散射因子接近的原子不可分辨，未归属峰单列杂相，被否方案留档
  • 打包自检时修掉 MCP 一个真缺陷：refine 工具把成功精修判成失败（本版 Project.refine() 恒返回 None）。 修前自检第 8 步中断 → 修后 12/12 步通过； 并把 GSAS-II 默认 3 轮迭代导致的 wR 63.80 %（shift/esd 55.1）暴露为显式收敛警告 新增 refine(max_cycles=12)：同一份官方样例数据收敛到 12.865 %（GOF 2.6876）
  • 全程留证：每个结论都有对应的 JSON / 哈希 / 复现脚本 —— 官方 PbSO₄ 样例的结果 JSON 与拟合图随包（verify/）， 运行日志按作者要求不对外，脚本可一键复现
精修 / 判定 / 画图三权分立 —— 画图只读 .gpx 并校验哈希； 口径先声明（仪器轮廓是否标定、Zero 分支、相集状态）再谈结论； 出现未解释强残差峰、相关度 ≥ 95 %、SVD 奇异时，停在"待科学复核"，不给漂亮但假的结论。
